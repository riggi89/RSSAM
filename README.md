Want to share your experience with RSSAM or provide general feedback?

👉 **[Browse General / Feedback](https://github.com/riggi89/RSSAM/discussions/categories/general)**

Use this category for:

- General discussions about RSSAM.
- Feedback about your experience.
- User-interface and usability feedback.
- Performance feedback.
- Steam game compatibility experiences.
- Installer and Portable experiences.
- Documentation suggestions.
- General community conversations.

Some questions you can answer:

- How do you like RSSAM?
- Does everything work as expected?
- Which features do you use most?
- How is the performance?
- Is the interface easy to understand?
- Have you found any compatibility problems?
- What could be improved?

Your feedback helps improve future versions of RSSAM.

### 💡 Ideas / Feature Requests

Have an idea for RSSAM or want to suggest an improvement?

👉 **[Create or browse Ideas / Feature Requests](https://github.com/riggi89/RSSAM/discussions/categories/ideas)**

Use this category for:

- New feature ideas.
- Improvement suggestions.
- User-interface improvements.
- Workflow improvements.
- Performance ideas.
- New configuration options.
- New Steam-related functionality.
- Suggestions for future RSSAM versions.

When suggesting a feature, it is helpful to explain:

- What you would like RSSAM to do.
- What problem the feature would solve.
- Why the feature would be useful.
- How you imagine the feature could work.
- Whether a similar feature exists in another application.
- Screenshots, examples, or mockups, if available.

> [!TIP]
> Before creating a new Discussion, please check whether a similar idea has already been suggested.

### 🙋 Q&A / Support

Do you have a question or need help with RSSAM?

👉 **[Ask a question or browse Q&A / Support](https://github.com/riggi89/RSSAM/discussions/categories/q-a)**

Use this category if you:

- Need help installing RSSAM.
- Have questions about configuration.
- Need help with the x86 or x64 version.
- Have problems with the Installer version.
- Have problems with the Portable version.
- Have questions about Steam games or achievements.
- Have questions about statistics.
- Have problems connecting RSSAM to Steam.
- Encounter an error and need help troubleshooting it.

When asking for technical help, please include as much information as possible:

- RSSAM version.
- Windows version.
- Architecture: x86 or x64.
- Installer or Portable version.
- A short description of the problem.
- What you expected to happen.
- What actually happened.
- Steps required to reproduce the problem.
- Error messages.
- Screenshots.
- Relevant log entries, if available.
